# NAVYK - Платформа для развития карьеры

## О проекте
NAVYK - это современная образовательно-карьерная платформа, соединяющая студентов, работодателей, менторов и университеты.

> **Статус:** Демо/MVP. Данные мокаются на клиенте, авторизация реализована через демо-контекст с набором встроенных пользователей. Настоящего бэкенда и базы данных пока нет.

## Основные возможности

### Для студентов
- Карьерные рекомендации
- Доступ к курсам и образовательным материалам
- Система достижений и геймификации
- Поиск стажировок и вакансий
- Менторство от профессионалов
- Аналитика прогресса обучения

### Для работодателей
- Поиск кандидатов
- Аналитика рынка труда
- Организация карьерных мероприятий
- Управление вакансиями

### Для университетов
- Аналитика трудоустройства
- Партнерства с работодателями
- Отслеживание прогресса студентов

### Для менторов
- Платформа для менторства
- Аналитика успехов подопечных

## Технический стек

### Frontend
- Next.js 15 (App Router)
- React 18
- TypeScript
- Tailwind CSS (shadcn/ui компоненты)
- framer-motion (анимации)
- recharts (графики)
- next-themes (тёмная тема)
- socket.io-client / WebSocket (заготовки для realtime)
- @tensorflow/tfjs (клиентские ML-эксперименты)

### Backend (заготовки)
- API-роуты Next.js (возвращают мок-данные)
- JWT (в планах)
- Демо-аутентификация через React Context (см. `context/auth-context.tsx`)

## Структура проекта

```
app/                  # Страницы (App Router)
  student/            # Дашборды и страницы студента
  employer/           # Дашборды работодателя
  university/         # Дашборды университета
  mentor/             # Дашборд ментора
  admin/              # Панель администратора
  api/                # API-роуты (мок-данные)
  components/         # Компоненты приложения
  lib/                # Утилиты, ML, auth, security
components/           # Базовые компоненты и UI-библиотека
context/              # React-контексты (auth)
hooks/                # Кастомные хуки
lib/                  # Утилиты, константы маршрутов
markdown/             # Статьи блога (в разработке)
public/               # Статические ассеты
UI-SAAS/              # Отдельный Storybook UI-kit (не подключён к приложению)
```

## Установка

```bash
git clone https://github.com/ElazAzel/NAVYK.git
cd NAVYK
npm install
npm run dev
```

Приложение будет доступно на http://localhost:3000

## Скрипты

- `npm run dev` - запуск в режиме разработки
- `npm run build` - продакшен-сборка
- `npm run start` - запуск продакшен-сборки
- `npm run lint` - проверка линтером
